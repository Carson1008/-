# 网易云音乐歌单音频保存

使用**本人已登录账号**的 `MUSIC_U` Cookie 获取歌单和可播放音频链接，直接保存返回的原始音频；不调用网易云客户端的“下载”接口，不解密受保护文件，也不借用第三方音源。仅保存账号当前有权播放且服务器提供原始音频的曲目。VIP 身份不保证所有歌曲都可获取：部分歌曲还受单曲购买、版权、地区、音源格式及接口变更限制，失败会逐首记录。

## 安装

需要 Python 3、`requests` 和图形界面所需的 `tkinter`：

```bash
pip install -r requirements.txt
python gui.py
```

在浏览器登录自己的网易云音乐账号，在浏览器开发者工具中确认 Cookie 的名称为 `MUSIC_U`；在图形界面直接填写对应的 Value，或者填写 `MUSIC_U=你的值`（也可粘贴包含 `MUSIC_U` 的 Cookie 字符串）。输入歌单链接或 ID，选保存目录并点击“下载整个歌单”。Cookie 仅在内存中使用，不写入日志/配置文件；请勿分享 Cookie 或截图。Cookie 过期时重新登录并复制。

命令行：

```bash
python main.py 'https://music.163.com/#/playlist?id=145258012' -o songs_dir
```

程序会不回显地询问 Cookie；也可以通过环境变量 `NCM_COOKIE` 提供（注意本机环境变量可能被其他本机程序读取）。保存文件名包含歌曲 ID，避免同名歌曲互相覆盖。仅支持服务器返回的未加密 MP3/FLAC 等音频；失败曲目不会产生伪装成音频的错误页。取消任务会清理未完成的 `.part` 文件。
